# Biomedical Text Simplification

Проект за опростяване на биомедицински текстове чрез NLP и transformer модели.

Кодът е подреден в папка `code/`, а документацията и презентацията са оставени отделно.

Основните експерименти сравняват Llama baseline, FLAN-T5, BioBART, knowledge graph подход и action-classifier pipeline.
